# Сайт-приглашение 🕸

Один файл — `index.html`. Больше ничего не нужно: шрифты и всё оформление внутри.

## Как посмотреть
Просто **дважды кликни `index.html`** — откроется в браузере. Интернет нужен только для подгрузки шрифтов.

## Что менять каждый год
Открой `index.html` в «Блокноте» (или в любом редакторе) и найди блок:

```
const CONFIG = { ... };
```

Это **единственное место**, которое нужно править. Внутри всё подписано:

| Что | Поле |
|-----|------|
| Имя именинника | `name` |
| Возраст | `age`, `ageWord` («лет»/«года»/«год») |
| Дата | `dateDay`, `dateMonth`, `dateFull`, `weekday`, `time` |
| Место и адрес | `place`, `address` (по адресу строятся ссылки на карты) |
| Координаты для маршрута в 1 тап | `coords` (напр. `"55.7558,37.6173"`, по желанию) |
| План вечера | `plan` |
| Расписание электричек | `trainUrl` |
| Ссылка на общий плейлист | `playlist` |
| Правила | `rules` |
| Коктейли | `recipes` |

### Фото в галерею
1. Положи фотографии рядом с `index.html` (удобно — в папку `images/`).
2. Впиши их в `photos`:
```js
photos: [
  { src:"images/2023-1.jpg", alt:"У костра прошлым летом" },
  { src:"images/2023-2.jpg", alt:"Общее фото за столом" },
],
```
Пока список пустой — показываются красивые рамки-заглушки.

### Ссылка на плейлист Яндекс.Музыки
Создай общий плейлист с доступом на добавление, скопируй ссылку и вставь в `playlist`.
Гостям для добавления треков нужен Яндекс Плюс (это уже написано на странице).

### Карта (по желанию)
Если хочешь встроенную карту: Яндекс.Карты → «Поделиться» → «Вставить код» → скопируй адрес из `src="..."` и вставь в `mapEmbed`. Без неё показывается стилизованная карта-рисунок с кнопками маршрутов.

## Как выложить в интернет (чтобы скинуть ссылку)
Самое простое, без регистрации:
1. Зайди на **app.netlify.com/drop**
2. Перетащи туда `index.html` (или всю папку, если есть фото).
3. Получишь ссылку — её и кидай в чат.

Альтернативы: GitHub Pages или Cloudflare Pages (если хочешь постоянный адрес).
